# AI Voice Keyboard — Android prototype

**Status:** experimental. Not yet verified on the user's phone. Code kept on `prototype/ai-voice-keyboard` branch of an existing Airnovation repository. This is a temporary location, not production infrastructure.

## What it does
1. Install the debug APK generated by the cloud build workflow.
2. Launch **AI Voice Keyboard**; give microphone permission.
3. Enable the input method in Android Settings; select it from the keyboard picker.
4. Open a WhatsApp, Gmail, or other app text input. Press **Mic** and speak Chinese.
5. Review/edit transcript; press **AI English** to translate/clean up.
6. Review/edit English; press **Insert**. This **only inserts text** into the focused editor. You must still tap **Send** yourself.

There is no automatic reading, sending, WhatsApp API integration, accessibility scraping, or background messaging.

## Cloud build (no PC required)
GitHub Actions workflow: `.github/workflows/build-ai-voice-keyboard.yml`.
The workflow runs on pushes to the prototype branch and produces the artifact `ai-voice-keyboard-debug-apk`, containing `app-debug.apk`. On Android, use GitHub web (desktop site if necessary) -> repository -> Actions -> completed successful workflow -> Artifacts -> download ZIP -> extract -> install APK. On Android you may need to allow this browser/files app to install unknown apps. Only install if you trust the repository and build, and verify the workflow succeeded.

Android SDK 35, min SDK 26, Java 17, Android Gradle Plugin 8.9.2, Gradle 8.11.1. Debug builds use GitHub runner generated debug signing keys. Reinstallation/update across different cloud runners may require uninstalling the previous APK and losing app settings because debug key may change.

## AI setup and privacy
The optional OpenAI API key is entered directly in the app Settings screen, encrypted using Android Keystore AES-GCM, and never committed to source control. No key is bundled in the APK. A **separate OpenAI API account with billing/credits** is required for **AI English**; a ChatGPT subscription does not grant API usage. The app sends only the preview text (not WhatsApp history) to OpenAI when you press AI English. Requests specify `store: false` but OpenAI's applicable data handling terms still apply. Speech transcription uses the Android device's installed recognition service, which may use network processing. Avoid use for sensitive, confidential, regulated, or protected information without a formal privacy/security review.

This is a **voice-first** input method, not a complete touch-typing keyboard. Switch to your normal keyboard via **Other Keyboard** for ordinary typing, passwords, or apps that do not accept this input method. AI English requires internet access. Speech recognition depends on your device's speech service and microphone permissions. Some app fields may not accept the insertion method.

## Prototype limitations
- No offline translation; no live streaming translation.
- Speech recognition language is set to `zh-CN`; mixed-language accuracy varies.
- Password fields recognized by Android inputType disable voice, translation, and insertion; apps may classify sensitive fields inconsistently.
- User is responsible for reviewing AI output before inserting/sending.
- API errors keep original transcript; they do not send anything.
- Not security audited or signed for production; publicly visible source and APK artifacts.
- Future: proper normal typing keys, selectable Mandarin/English/Malay recognition, configurable tone and terminology, tests, stable release signing, move to a private dedicated repository.

## Technical notes
`VoiceKeyboardService` uses Android `InputMethodService`, `SpeechRecognizer`, and `InputConnection.commitText`. API conversion uses OpenAI Responses via HTTPS, model `gpt-4.1-mini`, with short style/terminology guidance.
