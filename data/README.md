# CND1 Sectional Door Knowledge Pack v1.0

Designed for an offline-first technician helper app.

Recommended app name: **Door Display Helper**

CND1 is not mainly numeric-code based. It uses display symbols, keyword-identifiable messages, D15 LED flash counts, and setup/procedure displays.

## Files
- cnd1_sectional_door_knowledge_pack_v1_0.json: main app-readable pack
- display_symbols.csv
- error_messages.csv
- d15_led_errors.csv
- procedures.csv
- ui_copy_zh.json
- cnd1_lookup_helper.ts
- codex_prompt.md

## Suggested input methods
1. Select display symbol
2. Search keyword: stop, slack, wicket, photocell, E09, SER, D15 1
3. Select D15 LED flash count
4. Procedure lookup

No login, no backend, no cloud AI, no case recording.
